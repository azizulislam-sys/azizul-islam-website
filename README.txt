PERSONAL WEBSITE STARTER — QUICK START

1. Extract this ZIP file to a folder on your laptop.
2. Open the folder.
3. Double-click index.html to preview your website in a browser.
4. To edit the website, install Visual Studio Code from https://code.visualstudio.com/
5. In VS Code, choose File > Open Folder and select this website folder.
6. Open index.html, style.css, and script.js to edit the site.

PERSONALIZE IT:
- Replace "Your Name" with your name in index.html.
- Edit the About Me and My Work text.
- Replace you@example.com with your email.
- Replace sample social links with your own links.
- To add your photo, put a photo file in this folder and ask for help changing the profile placeholder into an image.
